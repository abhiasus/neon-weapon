# Neon Weapon Cards (React + Vite)

    npm install
    npm run dev

Images: src/assets/guns/<id>-<level>.<png|jpg|jpeg|webp|avif>   (ids: m416, scar, ak117; levels 1-3)
Videos: src/assets/videos/<id>-<level>.<mp4|webm|mov>  or  <id>.mp4  (shown when user says "yes" in the chat)
Overwrite a file to replace it, no code change needed.
